# Материалы профиля

Знак 256 используется из собственного проекта 256gram. Основной растровый баннер подготовлен для этого профиля. Баннеры проектов — отдельные иллюстрации, а не скриншоты приложений.

Надписи на векторных баннерах построены по шрифту Unbounded. Условия шрифта сохранены в assets/Unbounded-LICENSE.txt.
