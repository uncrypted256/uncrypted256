# Материалы профиля

Знак 256 используется из собственного проекта 256gram. Основной растровый баннер подготовлен для этого профиля. Баннеры проектов — отдельные иллюстрации, а не скриншоты приложений.

Надписи на векторных баннерах построены по шрифтам Unbounded и Golos Text. Условия сохранены в assets/Unbounded-LICENSE.txt и assets/Golos-Text-LICENSE.txt.

Pantera Control сохраняет готические металлические буквы и фиолетовую палитру Pantera Store. На баннере нет портрета; надпись изменена на PANTERA CONTROL.
